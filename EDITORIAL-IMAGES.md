Generated with the built-in image_gen tool for this project. These are concept interiors and editorial scenes, not verified photographs of RZZ LAW's actual premises. Original generation prompts are retained in output/imagegen/rzzlaw/prompts.json in the project workspace and in the standalone photo archive.

The 24 optimized WebP files live in assets/images/editorial, with wide and 800px variants. Their combined size is about 2 MB; a page loads only its relevant images. Original PNGs are excluded from the theme ZIP and included in the separate photo archive.

All image defaults are editable in Appearance → Customize → RZZ LAW. Practice-area featured images take priority over the default generated banner. Custom imagery is retained when updating. A one-time upgrade clears only the former bundled hero2.jpg choices for these section images.

The homepage city hero and its mobile 40px button spacing are retained. Case Studies remains removed.

Validation: all image files checked and visually inspected; theme PHP syntax and isolated image selection, responsive banner markup and Customizer checks passed. The local database is stopped, so full WordPress/browser rendering of this revision has not been verified. Live demo deployment requires uploading the theme ZIP.
